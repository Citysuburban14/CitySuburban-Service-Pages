## Local review

Run `pnpm dev`, open `/services/`, and use a `livePath` from the catalog to review a landing page. Run `pnpm test:reference`, `pnpm typecheck`, `pnpm lint` and `pnpm build` to verify the changes.

To refresh a future reference update, download the directory and its pages into `../.reference-preview`, export existing Sanity service content with `scripts/export-retained-service-content.ts`, run `scripts/build-reference-pages.py`, `scripts/build-retained-service-pages.py`, `scripts/build-live-footer.py` and `scripts/add-service-content-fields.py`, then `pnpm content:import-reference-pages --refresh-design`. The native content fields expose section copy and images without changing the layout. FAQ and WebPage schema is synchronized with rendered Sanity edits. The importer backs up existing drafts outside the app and checks document revisions before changing requested design fields. It saves 41 landing drafts and a version 2.0.0 standard-template draft. Without the flag, it only creates missing landing drafts. No Sanity publishing or live production proxy activation was performed. New published Sanity reference pages render and appear in collection cards dynamically; the generic Worker needs no URL list or regeneration.
